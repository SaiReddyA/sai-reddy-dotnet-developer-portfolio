# Sai Reddy A — .NET Full Stack Developer Portfolio

Live: **https://saireddya.dev/**

Personal portfolio of **Sai Reddy A**, a .NET Full Stack Developer (C#, ASP.NET Core, Angular, SQL Server, Azure, AWS) based in Hyderabad, India.

## Features
- Command palette — press `/` or `Ctrl + K` to jump to any section or run actions (email, copy, LinkedIn, résumé, themes)
- Colour themes that cycle automatically every 8 seconds (pause / pick one from the palette, or press `T`)
- Light / dark mode (`L`), remembered per visitor
- Live GitHub repositories via the public GitHub API
- Contact form via Formspree
- SEO: JSON-LD (Person, ProfilePage, FAQPage), Open Graph / Twitter cards, sitemap, robots.txt, `llms.txt` for AI assistants
- No build step, no frameworks — plain HTML, CSS and JavaScript

## Deploy (GitHub Pages)
1. Push to `main`.
2. Repo → **Settings → Pages** → Source: *Deploy from a branch* → Branch `main` / `(root)` → Save.
3. Custom domain: enter `saireddya.dev` under Pages → Custom domain (the `CNAME` file already sets it) and tick **Enforce HTTPS**.

## Update content
Everything is in `index.html`. Résumé PDF lives in `assets/`.
